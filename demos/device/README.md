# Device Service demo
`original.css` contains the original base theme and scoped style bodies from `/home/kvaigon/Device_service/src/style.css`, `views/HomePage.vue`, and `components/DeviceCard.vue` (copied 2026-09-24). `demo.css` adapts the dimensions and accessible controls for an isolated portfolio iframe. No service code or live data is modified.
The demo uses the live catalogue's HyperX Cloud III S WL and DualSense product names, specs, and product photos. The image files are local copies from `http://201.51.25.200:3000/uploads/` so the portfolio does not depend on the service being available. Stock counts and PC 07 are demo fixtures. The interaction is vanilla JS and makes no API requests; CSP blocks connections and form submissions. No credentials, customer data, or runtime inventory files are included.
